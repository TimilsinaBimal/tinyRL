So, as we learned before, we introduce baseline to improve the stability of learning and help the model learn better.

For Baseline, we also feed the state of the system so it knows better about the current state and predicts much better.

Now, we have two separate models: one to predict the returns and another to predict actions. They both has their own set of parameters and don't share those.

The Baseline (Called Value function) predicts the returns, and we calculate the difference between actual returns and predicted returns. This difference is called Advantage

$$ A = G_t - V(s) $$

Now, our objective becomes;

$$ Objective = LogProbs * A $$

**But what will be the loss function of Critic model then?**

Well in critic model,  we predict the continuous value of return, so, we can use Mean Squared Error as the loss function which is 

$$ L_c = \frac{1}{n} \sum_{i=1}^{N}({Y_i - \tilde{Y}_i})^2 $$


**The Problems**

**1. The training it too slow, as the Critic model gets only one update per episode.**

*Solution*: To solve, this, we train the critic model for multiple iterations on the same data after each episode. This help the model to learn the pattern better as a result it can predict the returns better.

**2. The update becomes too large and gradients explode**

*Solution*: When the Actor model learns well, but the critic model cannot keep up, the advantage become large, the update becomes huge and the gradients explode. To solve those issues, we use gradient clipping and Normalize the advantages.

$$A_{normalilzed} = \frac{A -\mu}{\sigma + \alpha} $$

Here, 
1. $\alpha$ is very small number eg. $1e^{-8}$
2. $\mu$ : Mean Advantage
3. $\sigma$: Standard deviation of Advantage


Even after these fixes, training remains unstable for harder problems. As the actor improves, returns grow rapidly and the critic struggles to keep up, causing large advantages, large gradients, and destructive policy updates. 

In real life we use a bit modified Actor critic method called where we update the critic and policies after n-steps rather than every time steps. This helps us to get a bit better idea about the behaviour of the agent.

But it is still very inconsistent. So, this is where PPO solves those issues!
